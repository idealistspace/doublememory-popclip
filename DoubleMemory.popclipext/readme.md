# DoubleMemory for PopClip

Adds a **Save to DoubleMemory** button to the PopClip bar whenever you select text.

Selections go straight into the running [DoubleMemory](https://www.doublememory.com) app over its
`doublememory://` URL scheme, opened in the background so capturing never takes focus away from
what you are reading. Links are recognised and saved as links; plain text is saved as a note.

## Options

- **Hashtag** — optional tag added to every item this extension saves, for example `inbox`.

## Requirements

DoubleMemory 1.0 or later, installed and running.

## Notes

PopClip appears for text selections, so this extension captures text and links. Images reach
DoubleMemory through the share sheet, drag and drop, or the clipboard.
